Gmail setup (important)

  • Use a Gmail App Password, not your normal Gmail password.
  • Google Account → Security → enable 2-Step Verification → App passwords → create password → paste below.
  • PDFs are sent to the user profile email/Gmail (profile first). Ensure users have a valid email in /profile.
  • Leave App Password blank when editing if you want to keep the currently saved password.
Go to Passes
Security note: the App Password is stored in the database to allow automatic sending. Protect admin access and your database. For higher security, you can use environment variables in application.properties instead.
