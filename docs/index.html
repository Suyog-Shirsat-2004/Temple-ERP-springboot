Temple ERP – Enterprise Resource Planning System

A Java Spring Boot-based web application designed to digitize and simplify temple management operations, including darshan passes, room bookings, donations, restaurant orders, payments, and administrative workflows.

View GitHub Repository Project Report (PDF) Detailed Documentation
Live Backend App: The fully working Temple ERP application requires a Java backend server and MongoDB (it cannot run entirely on GitHub Pages).
Live App URL: Add the verified backend deployment URL here after deployment (e.g. Railway/Koyeb/Cloud Run/Render URL).

Darshan & Bookings

Manage devotee services digitally with streamlined workflows.

  • Darshan pass booking and verification
  • QR code generation and pass validation
  • Room booking management and tokens

Donations & Restaurant

Support temple operations with transparent records.

  • Donation management and receipts
  • Restaurant menu and multi-item orders
  • Billing, order tokens, and history

Admin & Automation

Centralized administration and automated outputs.

  • Admin dashboard and user management
  • PDF generation and downloads
  • Email notifications with attachments (configurable)

Project Features

  • User registration/login and admin login/dashboard
  • Darshan pass booking, approval flow, QR verification
  • Room booking and booking history/tokens
  • Donation management and receipt PDFs
  • Restaurant orders, billing, and order tokens
  • Payment/transaction tracking (as implemented)
  • PDF downloads, email notifications, profile and admin management
  • Responsive UI for mobile, tablet, and desktop

Technology Stack

Java 17 Spring Boot 3.3 Spring Security Spring Data MongoDB Thymeleaf HTML CSS JavaScript MongoDB Atlas (production) Docker Maven

Backend-capable hosting is required for full functionality (e.g. Railway, Koyeb, Cloud Run, Render). GitHub Pages hosts this static project page only.

How to Enable This GitHub Pages Site

  1. Open the repository on GitHub: Settings → Pages.
  2. Under Build and deployment, choose Deploy from a branch.
  3. Select branch main and folder /docs, then save.
  4. After publishing, the page URL will be: https://suyog-shirsat2004.github.io/Temple-ERP-Java/
